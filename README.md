# Experimento de cordas vibrantes

Este repositório reúne a documentação do aparato desenvolvido no Centro de Disseminação da Ciência (CDC) da Universidade Estadual de Santa Cruz (UESC) para o estudo de ondas estacionárias em cordas vibrantes. A documentação foi organizada para facilitar a consulta aos arquivos e a reprodução da montagem.

- [Modelagem 3D](modelagem/): arquivos das peças projetadas para impressão 3D.
- [Equipamentos e materiais](equipamentos/): lista dos equipamentos, materiais e componentes do aparato.
- [Metodologia](metodologia/): fluxograma e descrição das etapas de desenvolvimento, da análise da montagem de referência aos ensaios locais e às atividades de integração com o FREE.
